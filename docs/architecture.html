RV 板上的智能体如何控制 MuJoCo 里的 Panda

电脑只负责物理仿真、渲染和显示；感知、规划（调用 DeepSeek）、运动学和实时控制都在 RV 板上完成。两者之间只有一根网线（J1 / eth0）。

三、一个周期里数据怎么流动

  1. 电脑上的物理进程每 4 ms 发一个状态包（7 个关节角、速度、夹爪宽度）给板子的 rt_ctl。
  2. rt_ctl 在 CPU1 上按当前轨迹段插值出下一个关节目标，约 0.18 ms 内回包；电脑把目标交给 MuJoCo 的位置伺服。
  3. 智能体需要“看”时，通过 TCP 15002 向电脑要图像，板上感知算出积木位置和塔的顺序。
  4. 智能体把目标、当前状态、上一步结果整理成文字，经 SSH 隧道和电脑的 Clash 发给 DeepSeek，拿回 update_plan 和一个动作。
  5. 技能层用 IK 把动作拆成若干轨迹段，通过 /tmp/rt_ctl.sock 交给 rt_ctl 执行；执行完再观察、校验。
  6. 所有事件和每秒的主板数据通过 SSE 推到浏览器的工作台；四个视角画面由电脑直接推流到浏览器。
