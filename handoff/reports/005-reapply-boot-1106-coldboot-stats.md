## 需要回答的问题

1. **卡上的 uInitrd.lz4 是否已经是 boot_1106 版？** 是。Windows 回读和板上只读挂载回读均为 `82a45be4f417110b532bd785f1d49353025ad0b62046754e74ceb1ee2c84181b`，Windows 大小为 14,857,818 字节。7 次 RESET 后启动日志中的 ramdisk 读取量也均为 14,857,818 字节。其他三个启动文件的哈希与报告 004 一致。卡上原 backup-20261107 保留，未新增备份目录。
2. **5 次完全断电冷启动中几次直接成功，几次 invalid state，RESET 能否恢复？** 直接成功 0 次，串口实际收到 invalid state 为 0 次，其他 5 次，均在 120 秒窗口内无串口字节。每轮额外按一次 RESET，5/5 均到 login。本轮不能给出 invalid state 后恢复的成功率，因为没有观察到这一类事件。任务 004 中的新旧两版 OpenSBI 错误仍作为历史证据。
3. **2 次只按 RESET 的结果？** 2/2 成功到 login，期间主电和 USB 都持续连接。
4. **平时接法和 USB 部分供电情况？** 人说明平时先接主电，再接调试 USB。本次依任务单统一采用先 USB 后主电，每轮只接 USB 时均报告电源指示灯全灭，且主机能枚举 COM3。部分电路的实际供电电压未测。
5. **新镜像三处改动在板上是否确认？** 已确认 `/mount_emmc.sh` 存在，4420 字节、0755。`/etc/ssh/sshd_config` 有效行是 `PermitRootLogin yes`。`/etc` 和 `/etc/ssh` 均为 drwxrwxr-x，即 0775。内核仍是 6.6.90-rt54+ #6 SMP PREEMPT_RT，CPU online=0-1。

TF 卡身份通过 `/sys/block/mmcblk0/device/type=SD` 和 62,333,952 个扇区核对，eMMC 为 mmcblk1、type=MMC。确认 /media 未挂载后，将 /dev/mmcblk0p1 只读挂载到 /media，回读目标哈希并卸载，日志中有 TF_CARD_UNMOUNTED。当前卡保留 boot_1106，登录会话仍在板上，串口已释放。
